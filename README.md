# 雅思学术类备考台 · IELTS Academic Workbench

一个**单文件、零依赖、断网可用**的 HTML 备考工作台。核心是艾宾浩斯背词队列，辅以刷题记录、错本和考试倒计时。

> 在线访问：开启 Pages 后为 `https://RLiu-2024.github.io/<仓库名>/`
> 手机：浏览器打开 → 分享 → 添加到主屏幕，即可当 App 用

## 功能

### 背词队列
- 内置 **48 个高频词**，含单词、音标、词性、释义、常考搭配
- 每天自动发 **10 个新词**（1–40 可调），与到期复习旧词合并为今日队列
- 专注背词页：大单词 + 大音标 → 翻面看释义 → 认识 / 不认识
- **认识** → 升级，复习间隔按 **1 / 2 / 4 / 7 / 15 / 30 天**推进，6 级后毕业
- **不认识** → 降级 + 回到今日队尾 + 自动收进生词本；**当天连续 3 次不认识**改到明天
- 昨日未完成的新词自动滚入今天；队列清零有庆祝动效

### 刷题记录（听力 / 阅读 / 写作 / 口语）
- 记录日期、科目、题量、正确数、备注，自动计算正确率
- 近 14 天正确率折线图（内联 SVG，可切单科，含 80% 基准线）
- 附雅思学术类题型结构说明卡（以官方最新大纲及官方公告为准）

### 错本
- 生词本：不认识自动收编，可发音、可移出
- 错题本：记录题型、错因、题目、正确思路，按 **1 / 3 / 7 / 15 / 30 天**复习
- 到期自动置顶标红，可按题型 + 错因筛选

### 今日与数据
- 顶部「今天要处理」：剩余单词 / 未记录刷题 / 到期错题，各带一键入口
- 考试倒计时（可改日期）、今日任务清单
- 环形进度、近 30 天打卡热力图、连续背词天数
- 导出今日战绩竖版 PNG（750×1334）

## 使用

直接双击 `index.html`，或把它丢进任意浏览器 / 网盘 / 静态托管。

## 数据说明

- 数据保存在**本机浏览器的 localStorage**（键名 `wb_ielts_ac_v1`），**不上传任何服务器**
- 换设备、清缓存、换浏览器都会丢失 → 请在「我的」页**定期导出 JSON 备份**
- 累计 20 条记录后会出现备份提醒
- 「只清除示例数据」只删预置示例，不动你的记录；「清空全部数据」需手动输入 `清空` 二字

## 技术约束

- 单文件 HTML，CSS / JS 全内联，**不引用任何外部框架、CDN、字体或图表库**
- 图表与图标均为**手写内联 SVG**，不使用 emoji
- 无任何网络请求，断网、离线、本地文件协议下均完整可用
- 发音调用系统 `speechSynthesis`，设备不支持时按钮自动隐藏
- 响应式：手机底部四 Tab / 平板顶部横向导航 / 电脑左侧固定边栏 + 双栏

## 开发备注

- 已通过 jsdom 真实运行时冒烟测试 100 项，零运行时错误
